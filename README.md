# 🐧 Valentine's Card

A tiny, single-page website that won't take no for an answer

Just three files and two penguins:

```
index.html
app.js
start.png
happy.png
```

Open `index.html` in a browser, or drop the whole folder onto any basic web server or static host (GitHub Pages, Netlify, S3 or whatever)

Swap in your own pictures, but keep the filenames the same and keep them in the same folder as `index.html`:

| File | Shown when |
| --- | --- |
| `start.png` | The page first loads, before anyone answers |
| `happy.png` | After someone says Yes 💖 |
