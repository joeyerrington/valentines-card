# 🐧 Valentine's Card

A tiny, single-page website that asks an important question, and doesn't take no for an answer

Spoiler: there is no winning move except Yes.

## Run it

No build step, no dependencies, no fuss. Just three files and two penguins:

```
index.html
app.js
start.png
happy.png
```

Open `index.html` in a browser, or drop the whole folder onto any basic web server or static host (GitHub Pages, Netlify, Apache, nginx, whatever you've got).

## Use your own images

Swap in your own pictures, but keep the filenames the same and keep them in the same folder as `index.html`:

| File | Shown when |
| --- | --- |
| `start.png` | The page first loads, before anyone answers |
| `happy.png` | After someone says Yes 💖 |
